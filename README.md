# Circle Calculator Project

## Overview
The **Circle Calculator** is a robust Java application that computes the fundamental geometric properties of a circle (diameter, circumference, and area). It demonstrates object-oriented principles and strict exception handling for user inputs.

## Features
* **Exception Handling:** Robust against `InputMismatchException` to prevent crashes from invalid (non-numeric) user input.
* **OOP Architecture:** Clear separation of concerns between the execution logic (`Mainmain`) and the domain model (`Circle`).
* **Automated Documentation:** 
  * `Circle.java` is documented using standard **Javadoc**.
  * `Mainmain.java` is documented using customized **Jautodoc** templates.
